# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be respectful and constructive, assume good faith, and keep
discussions about the work. Harassment or discrimination of any kind is not
tolerated, in issues, pull requests, or anywhere else this project is
discussed.

To report a concern, contact the maintainers privately through a
[security advisory](https://github.com/elva-labs/claude-stats/security/advisories/new)
(it reaches only the maintainers) or via the organisation's contact details on
[github.com/elva-labs](https://github.com/elva-labs). Reports are handled
confidentially.
